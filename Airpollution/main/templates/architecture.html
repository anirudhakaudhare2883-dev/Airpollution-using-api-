Machine Learning Pipeline

A completely overhauled, highly sequential architecture tracking the exact flow of data—from frontend geographic resolution to the final ensemble tree prediction.

1. Geospatial Resolution Engine

The client side initiates the pipeline by securely translating regional string inputs (City, State, Country) into fixed mathematical Latitude and Longitude bounding coordinates.

Nominatim Geocoding Float Validation

2. Asynchronous Telemetry Bridge

A secure Python backend extracts real-time environmental data streams from external sensors via concurrent HTTP requests, gathering critical PM2.5, PM10, and Ozone vectors.

Python Requests JSON Parsing

3. Vectorized Feature Engineering

The raw telemetry is injected into memory, mapped to structured DataFrames, and mathematically scaled ensuring standard distribution matching for precise inference.

Pandas Matrix MinMax Scaling

4. Ensemble Random Forest Inference

The pre-trained model unpickles its decision structure, propagating the normalized feature vector through over 100 deep-split estimators to calculate the definitive AQI score.

Scikit-Learn Joblib Aggregation

5. Interface Dynamic Binding

The Flask WSGI framework completes the cycle, dynamically rendering the response data into the DOM. This generates the final interactive glassmorphic dashboard output.

Jinja2 Engine Chart.js Binding
