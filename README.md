## 🧠 Machine Learning Architecture

```
┌─────────────────────────────────────────────────────────────────────┐
│                        INPUT LAYER                                  │
│   PM2.5  PM10  NO₂  SO₂  CO  O₃  Temp  Humidity  Wind  Pressure   │
└───────────────────────────┬─────────────────────────────────────────┘
                            │
              ┌─────────────▼─────────────┐
              │    Feature Engineering    │
              │  Normalization · Encoding │
              └─────────────┬─────────────┘
                            │
         ┌──────────────────┼──────────────────┐
         ▼                  ▼                  ▼
  ┌─────────────┐    ┌─────────────┐    ┌──────────┐
  │🌲 Random    │    │⚡ XGBoost   │    │🧠 LSTM   │
  │   Forest   │    │  Booster   │    │  (t-seq) │
  └──────┬──────┘    └──────┬──────┘    └────┬─────┘
         └──────────────────┼──────────────────┘
                            │
              ┌─────────────▼─────────────┐
              │    Ensemble Aggregator    │
              │   Weighted Vote · Stack   │
              └─────────────┬─────────────┘
                            │
              ┌─────────────▼─────────────┐
              │       AQI OUTPUT          │
              │   Value + Category +      │
              │   Health Advisory         │
              └───────────────────────────┘
```

## 🚀 Quick Start

### Prerequisites
```bash
Python >= 3.10
Node.js >= 18.x (for React frontend)
pip
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/anirudhakaudhare2883-dev/Airpollution-using-api-.git
cd Airpollution-using-api-

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. (Optional) Install frontend dependencies
cd frontend && npm install && cd ..

# 4. Launch the Flask server
python app.py
```

### Access the App
```
🌐  http://127.0.0.1:5000
```
