# ✨ Project Overview

The **Air Quality Prediction System** is an AI-powered environmental monitoring platform developed using **Machine Learning** and **real-time environmental APIs** to predict the **Air Quality Index (AQI)** accurately.

The system analyzes pollutants such as:

* PM2.5
* PM10
* NO₂
* SO₂
* CO
* O₃

along with meteorological parameters like:

* Temperature
* Humidity
* Wind Speed
* Atmospheric Pressure

to generate intelligent AQI predictions and health insights.
